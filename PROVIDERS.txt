== 3. keys: ~/.config/openapi/keys.env (mode 600) - see keys.env.example ==
fast way: ./openapi.py init   (hidden prompt per provider, Enter skips)
one key:  ./openapi.py add NAME [KEY]

== 4. routing rules (implemented) ==
429 -> provider rests retry-after (default 60 s), next provider/model at once
connection error / 5xx -> provider rests 30 s
rejected key (401/403) -> provider dead for the session
model listed but refused (404/400/403/422) -> remembered bad, next ranked model (3 tries)
explicit 'provider/model' never fails over to another provider
